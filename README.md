# Лабораторная работа №2 — обнаружение зажигалок с YOLO26n

## Цель
Дообучение YOLO26n для обнаружения объектов класса `lighter`.

## Датасет
- Всего размеченных изображений: 42.
- Train: 34 изображения.
- Validation: 8 изображений.
- Класс: `lighter`, ID: 0.
- Разметка выполнена в CVAT, формат Ultralytics YOLO Detection.

## Обучение
Обучение выполнено в течение 20 эпох на CPU.

Команда запуска:

    python scripts/train.py

Лучшие веса: `outputs/training/lighter/weights/best.pt`.

Метрики на валидации:
- Precision: 0.707
- Recall: 0.875
- mAP@50: 0.854
- mAP@50-95: 0.411

Из-за небольшого размера валидационной выборки результаты предварительные.

## Инференс
Тестовые изображения хранятся в `data/test/`.

Команда запуска:

    python scripts/predict.py

Результаты с рамками: `outputs/test_predictions/`.
JSON-отчёт: `outputs/detections.json`.

## Сравнение моделей
Команда запуска:

    python scripts/compare_models.py

Отчёт: `outputs/model_comparison.json`.

Исходная YOLO26n обучена на COCO и не имеет пользовательского класса
`lighter`. Для объективной оценки на тестовых данных нужны эталонные разметки.

## Структура
- `data/dataset/` — датасет.
- `data/test/` — тестовые изображения.
- `scripts/` — скрипты проекта.
- `outputs/` — результаты обучения и инференса.

## Примечание
Файлы весов модели не включаются в Git. Для повторения эксперимента
необходимы датасет, исходные веса YOLO26n и зависимости проекта.
