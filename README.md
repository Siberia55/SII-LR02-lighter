# Лабораторная работа №2 — обнаружение зажигалок с YOLO26n

## 1. Цель работы

Дообучить модель YOLO26n для обнаружения объектов класса `lighter` (зажигалка), выполнить инференс на тестовых изображениях, сохранить результаты в JSON и сравнить исходную и дообученную модели.

## 2. Используемые технологии

- Python 3.10+
- Ultralytics YOLO26n
- PyTorch
- CVAT для разметки изображений
- Формат датасета Ultralytics YOLO Detection

## 3. Датасет

Размечено 42 изображения:

- Train: 34 изображения.
- Validation: 8 изображений.
- Класс: `lighter`, ID класса: `0`.
- Разметка выполнена в CVAT.

Тестовая выборка содержит 5 изображений и хранится в `data/test/`.

Конфигурация датасета: `data/dataset/data.yaml`.

Из-за небольшого размера датасета и валидационной выборки результаты следует считать предварительными.

## 4. Установка и запуск

### Требования

Python 3.10 или новее. Обучение можно выполнять на CPU; GPU не обязателен, но на CPU оно занимает больше времени.

### Установка зависимостей

Создать виртуальное окружение и установить зависимости:

    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install --upgrade pip
    pip install -r requirements.txt

Если виртуальное окружение уже создано, повторно создавать его не нужно.

### Исходные веса

Исходные веса YOLO26n — `yolo26n.pt`. Файлы весов `.pt` не хранятся в Git-репозитории. Перед запуском обучения необходимо получить исходные веса YOLO26n и поместить файл `yolo26n.pt` в корень проекта.

Обученные веса сохраняются в `outputs/training/lighter/weights/`. Они также исключены из Git, поэтому для повторного инференса обученную модель нужно получить отдельно или выполнить обучение заново.

## 5. Обучение модели

Запуск:

    python scripts/train.py

Обучение выполнялось в течение 20 эпох на CPU.

Лучшие веса после обучения:

    outputs/training/lighter/weights/best.pt

### Метрики на валидационной выборке

| Метрика | Значение |
|---|---:|
| Precision | 0.707 |
| Recall | 0.875 |
| mAP@50 | 0.854 |
| mAP@50-95 | 0.411 |

Метрики рассчитаны на 8 валидационных изображениях, поэтому они могут существенно измениться на более крупном и разнообразном наборе данных.

## 6. Инференс

Тестовые изображения находятся в `data/test/`.

Запуск:

    python scripts/predict.py

Результаты предсказаний и JSON-отчёт сохраняются в:

- `outputs/test_predictions/` — изображения с рамками;
- `outputs/detections.json` — результаты обнаружения в JSON.

Папка `outputs/test_predictions/` генерируется при запуске и не включена в Git. Примеры результатов, сохранённые в репозитории, находятся в `outputs/finetuned_predictions/`.

## 8. Сравнение моделей

Запуск:

    python scripts/compare_models.py

JSON-отчёт:

    outputs/model_comparison.json

Исходная YOLO26n использует предобученные классы COCO и не содержит пользовательского класса `lighter`. Поэтому сравнение количества обнаружений исходной и дообученной моделей не является полноценным сравнением точности обнаружения зажигалок.

Для объективного сравнения на тестовой выборке необходимы эталонные разметки и расчёт метрик по ним.

## 10. Воспроизводимость

Чтобы повторить эксперимент:

1. Клонировать репозиторий.
2. Установить зависимости из `requirements.txt`.
3. Получить исходные веса `yolo26n.pt`.
4. Проверить наличие датасета и конфигурации `data/dataset/data.yaml`.
5. Запустить `python scripts/train.py`.
6. Запустить `python scripts/predict.py` для получения предсказаний.

Параметры обучения задаются в `scripts/train.py`.

## 11. Ограничения

- Датасет небольшой: 42 размеченных изображения.
- Валидационная выборка состоит из 8 изображений.
- Тестовая выборка состоит из 5 изображений.
- Обучение выполнялось на CPU.
- Для объективной оценки качества на тестовых данных нужны эталонные разметки.

Полученные результаты демонстрируют процесс дообучения и применения модели, но не гарантируют такую же точность на новых изображениях.
